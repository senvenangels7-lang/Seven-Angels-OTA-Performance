# Seven Angels OTA Performance Dashboard

A browser-based OTA performance dashboard for Seven Angels properties.

## Included

- Dashboard overview
- Seven Angels OTA channel performance
- Revenue, room nights, ARR and occupancy
- Hotel-wise and OTA-wise analysis
- Market segment reporting
- Last Year vs This Year reporting
- Excel workbook import
- Data entry and CSV export
- Browser-based saved dataset

## Run locally

Open `index.html` in Chrome, Edge, Firefox or Safari.

## Publish with GitHub Pages

1. Create a new GitHub repository.
2. Upload `index.html` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`.
6. Save and wait for GitHub Pages to publish the site.

The dashboard is a static HTML application and does not require a server.

## Important data note

Excel uploads are stored in the browser's local storage. They are not automatically written back to GitHub. If the dashboard is opened on another computer/browser, its locally saved data will not automatically appear there.

The supplied dashboard already supports Excel upload and browser-side persistence.
